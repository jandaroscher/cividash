# 8. Glossar

Begriffe und Abkürzungen.

| Begriff | Erklärung |
|---------|-----------|
| **Admin** | Rolle mit systemweitem Vollzugriff auf alle Dashboards, Einstellungen und die Benutzerverwaltung, unabhängig vom gerade gewählten Dashboard. Siehe [Kapitel 7, Rollen und Berechtigungen](07-rollen-und-berechtigungen.md). |
| **Aktiv-Schalter** | Schalter an Seiten, Kacheln, Blöcken, Kategorien und weiteren Elementen, der die Sichtbarkeit im Frontend steuert, ohne den Eintrag zu löschen. Ein deaktiviertes Element bleibt im Adminbereich vollständig bearbeitbar. Siehe [Kapitel 2.1, Seitenübersicht und Status](02-seiten-verwalten.md). |
| **Backend-Sprache** | Im Profil hinterlegte Sprache, die die Oberfläche des Adminbereichs selbst (Menüs, Buttons, Labels) bestimmt — zu unterscheiden vom Sprache-Umschalter für Inhalte (siehe **Locale**). Siehe [Kapitel 6, Einstellungen](06-einstellungen.md). |
| **Block** | Einzelnes Inhaltselement einer Seite oder Kachel-Hintergrundseite (z. B. Intro-Text, Slider, FAQ), das sich frei kombinieren, sortieren und aktivieren/deaktivieren lässt. Siehe [Kapitel 2.4, Inhaltsblöcke verwenden](02-seiten-verwalten.md). |
| **CIVITAS** | Optionale externe Integration, die sich je Dashboard aktivieren lässt. Ist sie aktiv, steht auf der Kachel-Bearbeitungsseite zusätzlich die Admin-only-Aktion **An CORE veröffentlichen** bereit. Siehe [Kapitel 7, Rollen und Berechtigungen](07-rollen-und-berechtigungen.md). |
| **CORE** | Externes Zielsystem, an das sich Kacheln veröffentlichen lassen, sobald die CIVITAS-Integration für das jeweilige Dashboard aktiviert ist. Siehe [Kapitel 7, Rollen und Berechtigungen](07-rollen-und-berechtigungen.md). |
| **Hintergrundseite** | Detailansicht einer Kachel, die sich beim Klick auf die Kachel im Frontend öffnet und eigene Inhaltsblöcke enthält. Siehe [Kapitel 3.3, Hintergrundseite bearbeiten](03-kacheln-verwalten.md). |
| **Kachel (Tile)** | Inhaltselement der Dashboard-Übersicht: ein anklickbarer Kasten mit Titel, Icon und Kennzahlen, der zu einer eigenen Hintergrundseite führt. Siehe [Kapitel 3, Kacheln verwalten](03-kacheln-verwalten.md). |
| **Kategorie** | Einzelner Filterwert innerhalb einer Kategoriegruppe (z. B. „Mobilität" innerhalb „Handlungsfelder"), der Kacheln zugeordnet werden kann. Siehe [Kapitel 4.2, Kategorien anlegen und bearbeiten](04-kategorien.md). |
| **Kategoriegruppe** | Strukturebene oberhalb einzelner Kategorien, fasst inhaltlich zusammengehörige Kategorien zu einem Filterthema zusammen (z. B. „Handlungsfelder"). Siehe [Kapitel 4.1, Kategoriegruppen](04-kategorien.md). |
| **Kennzahl (Metrik)** | Messwert, der einer Kachel zugeordnet ist und über Zeiträume hinweg erfasst wird (z. B. „CO₂-Ausstoß" in Tonnen pro Jahr). Siehe [Kapitel 3.4, Kennzahlen definieren](03-kacheln-verwalten.md). |
| **Locale** | Sprachversion eines Inhalts (Deutsch/Englisch), zwischen der sich über den Sprache-Umschalter wechseln lässt; Titel, Blöcke, URL-Slug und Metadaten sind pro Locale vollständig getrennt. Siehe [Kapitel 2.7, Mehrsprachige Inhalte](02-seiten-verwalten.md). |
| **Lottie** | Animationsformat für Icons: `.json`-Dateien im Bodymovin/Lottie-Format oder `.lottie`-Dateien (dotLottie-Container), alternativ zu einem statischen Bild. Siehe [Kapitel 5.4, Sonderformate: Lottie-Animationen, SVG-Icons](05-bilder-und-dateien.md). |
| **Metadaten** | SEO-Titel, -Beschreibung und -Bild einer Seite oder Kachel, verwendet für Suchmaschinen und Social-Media-Vorschauen. Siehe [Kapitel 2.6, Metadaten pflegen](02-seiten-verwalten.md). |
| **Redaktion** | Rolle mit Zugriff auf Inhaltspflege (Seiten, Kacheln, Kategorien) innerhalb zugewiesener Dashboards, jedoch ohne Zugriff auf Einstellungen und Benutzerverwaltung. Siehe [Kapitel 7, Rollen und Berechtigungen](07-rollen-und-berechtigungen.md). |
| **Slug** | Adressteil einer Seite, Kachel oder eines Dashboards, der die URL bestimmt (z. B. `?tenant=slug`); wird beim Tippen des Titels automatisch vorgeschlagen. Siehe [Kapitel 2.2, Neue Seite anlegen](02-seiten-verwalten.md). |
| **Tenant / Dashboard** | Eigenständiger Mandant der Installation mit eigenen Seiten, Kacheln, Kategorien und eigenem Branding; Wechsel über die Dashboard-Auswahl in der Seitenleiste. Siehe [Kapitel 1.1, Anmeldung und Oberfläche](01-erste-schritte.md). |
| **Zeitraumwert** | Einzelner Messwert einer Kennzahl für einen bestimmten Zeitraum (z. B. das Jahr „2024"); die Zeitgranularität legt das Eingabeformat fest. Siehe [Kapitel 3.4, Kennzahlen definieren](03-kacheln-verwalten.md). |
