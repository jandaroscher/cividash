# 8. Glossary

Terms and abbreviations.

| Term | Explanation |
|------|-------------|
| **Active toggle** | Switch on pages, tiles, blocks, categories, and other elements that controls frontend visibility without deleting the entry. A disabled element remains fully editable in the admin panel. See [Chapter 2.1, Page Overview and Status](02-managing-pages.md). |
| **Admin** | Role with system-wide full access to all dashboards, settings, and user management, regardless of the currently selected dashboard. See [Chapter 7, Roles and Permissions](07-roles-and-permissions.md). |
| **Backend language** | Language set in the profile that determines the interface language of the admin panel itself (menus, buttons, labels) — distinct from the locale switcher used for content (see **Locale**). See [Chapter 6, Settings](06-settings.md). |
| **Background page** | A tile's detail view, opened by clicking the tile on the frontend, containing its own content blocks. See [Chapter 3.3, Edit Background Page](03-managing-tiles.md). |
| **Block** | A single content element on a page or tile background page (e.g. Intro Text, Slider, FAQ) that can be freely combined, sorted, and enabled/disabled. See [Chapter 2.4, Using Content Blocks](02-managing-pages.md). |
| **Category** | A single filter value within a category group (e.g. "Mobility" within "Action Fields") that can be assigned to tiles. See [Chapter 4.2, Create and Edit Categories](04-categories.md). |
| **Category Group** | Structural level above individual categories, bundling categories that belong to the same filter topic (e.g. "Action Fields"). See [Chapter 4.1, Category Groups](04-categories.md). |
| **CIVITAS** | Optional external integration that can be enabled per dashboard. When active, the tile editing page additionally offers the admin-only **Publish to CORE** action. See [Chapter 7, Roles and Permissions](07-roles-and-permissions.md). |
| **CORE** | External target system tiles can be published to once the CIVITAS integration is enabled for the relevant dashboard. See [Chapter 7, Roles and Permissions](07-roles-and-permissions.md). |
| **Editor** | Role with access to content management (pages, tiles, categories) within assigned dashboards, but without access to settings or user management. See [Chapter 7, Roles and Permissions](07-roles-and-permissions.md). |
| **Locale** | Language version of content (German/English), switched via the locale switcher; title, blocks, URL slug, and metadata are completely separate per locale. See [Chapter 2.7, Multilingual Content](02-managing-pages.md). |
| **Lottie** | Animation format for icons: `.json` files in Bodymovin/Lottie format, or `.lottie` files (dotLottie container), used as an alternative to a static image. See [Chapter 5.4, Special Formats: Lottie Animations, SVG Icons](05-images-and-files.md). |
| **Metadata** | SEO title, description, and image for a page or tile, used for search engines and social media previews. See [Chapter 2.6, Manage Metadata](02-managing-pages.md). |
| **Metric** | A measurement assigned to a tile and tracked across periods (e.g. "CO2 emissions" in tons per year). See [Chapter 3.4, Define Key Figures](03-managing-tiles.md). |
| **Period value** | A single measurement of a metric for a specific period (e.g. the year "2024"); the time granularity determines the input format. See [Chapter 3.4, Define Key Figures](03-managing-tiles.md). |
| **Slug** | Address segment of a page, tile, or dashboard that determines the URL (e.g. `?tenant=slug`); auto-suggested while typing the title. See [Chapter 2.2, Create a New Page](02-managing-pages.md). |
| **Tenant / Dashboard** | Independent instance within the installation with its own pages, tiles, categories, and branding; switched via the dashboard selector in the sidebar. See [Chapter 1.1, Login and Interface](01-getting-started.md). |
| **Tile** | A content element on the dashboard overview: a clickable box with a title, icon, and metrics that leads to its own background page. See [Chapter 3, Managing Tiles](03-managing-tiles.md). |
