## What Is CiviDash?

CiviDash is an open-source dashboard for municipalities that presents local key figures and topics — such as sustainability and urban development — clearly on the web. It is modeled on Regensburg's "Zukunftsbarometer" (zukunft.regensburg.de).

Content is organized as **tiles** with key figures alongside supplementary information pages, and is displayed automatically in the frontend. You maintain everything conveniently in the admin panel — no programming knowledge required.

At a glance:

- **Built for municipalities:** brings the Zukunftsbarometer concept to any city or organization.
- **Tiles with key figures:** indicators are visualized clearly, and visitors can filter by topic.
- **Bilingual (DE/EN):** both the interface and content can be maintained in German and English.
- **Custom look and feel:** logo, colors, and typography are configurable (white-label).
- **Responsive:** works on desktop, tablet, and smartphone.

CiviDash is open source and can be self-hosted by municipalities.

## About This Guide

This guide is intended for everyone working with the content management system — especially editorial staff and administrators. It covers everyday tasks in the admin panel: managing pages, maintaining tiles, structuring categories, and configuring system-wide settings.

No technical background is required. The guide assumes access to the admin panel and basic experience with web browsers.
